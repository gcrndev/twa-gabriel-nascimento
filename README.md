# TWA — Ficha 01

Trabalho individual de Tecnologias Web Avançadas.

## Estrutura

- `twa-ficha01/`: módulo ES e script que consulta a API pública do GitHub e grava `repo.json`.
- `twa-vite/`: projeto Vite vanilla com contador decrescente e valor no título do separador.

## Executar

```bash
cd twa-ficha01
npm run module
npm run api

cd ../twa-vite
npm install
npm run dev
```

## Ferramentas

- Node.js: requisito da ficha: 22.x LTS. Ambiente local usado na preparação: 24.15.0.
- npm: 11.6.1
- Git: 2.50.1
